1登入系統

步驟 1　開啟天鷹保全 APP 網址，等待金色光環啟動動畫。
步驟 2　輸入你的 工號 與 密碼。
步驟 3　可勾選 記住我，下次自動登入。
步驟 4　按「登入」，看到「✅ 登入成功」即進入首頁。
⚠️ 工號不存在或密碼錯誤會有紅色提示。忘記密碼請洽主管或管理員重設。

修改密碼

進入後可於設定處修改密碼，輸入舊密碼與兩次新密碼即可。

2認識首頁

登入後首頁由上而下：

  • 問候與身分：顯示你的姓名、部門、職務。
  • 📢 公告橫幅：點一下可查看全部公告。
  • 四格統計卡片：可用工具數、公告數、常用工具數、今天日期。
  • ⭐ 常用工具快捷：你加入收藏的工具會出現在這裡，一鍵開啟。

把工具加入「常用」

到「工具」頁 → 點工具卡片右上角的 ⭐ → 該工具就會出現在首頁常用快捷。再點一次取消。

4常用工具操作教學

📋 事故報告填寫
現場管理
  1. 選擇事故日期與時間（預設為現在）。
  2. 填寫事故地點、選事故類別（一般事故／竊盜／爭執／設備故障／意外受傷／火警…）。
  3. 詳細描述事故經過。
  4. 可上傳現場照片（最多 3 張），點＋上傳。
  5. 按「提交事故報告」，看到綠色成功提示即送出，2 秒後返回主選單。
送出後主管會在後台看到此筆並處理；你不需要做其他動作。
🚨 匿名表揚／反應
緊急應變
  1. 選擇類型：表揚 或 反應（檢舉／反映）。
  2. 填寫對象（被表揚或反映的人員姓名／工號）。
  3. 選事由分類、填事件描述、選發生日期。
  4. 可附圖片（最多 5 張）。
  5. 送出 → 看到「提交成功」。
🔒 前台完全匿名，你的身分不會顯示在報告上。（後台僅供主管辨識防濫用，一般不對外。）
🔒 打烊後 / 🔓 開店前進出快速登錄
核心工具
  1. 於「登錄」頁選擇專櫃／廠商、監工人員、檢查者。
  2. 填進場時間／退場時間。
  3. 送出 → 自動寫入雲端試算表。
  4. 切到「今日」頁可查看當天已登錄紀錄。
大量貼上時系統會自動去重，避免重複登錄。
📅 班表查詢
人事管理

選月份／自己的工號即可查看班別。班別代號（早班 A/S/L/H…、晚班 B/海/N、休假等）會以顏色區分。

📝 請假申請
人事管理

可在 APP 內申請，或用 LINE 機器人 申請（見《LINE 機器人操作手冊》）。選擇請假日期與原因送出，等待主管審核，結果會通知你。

📞 緊急聯絡清單
緊急應變

查詢各單位緊急聯絡電話。手機號碼開頭的 0 會正確顯示。

📋 今/明日哨表
核心工具
  1. 頂部有 ☀️ 今日 / 🌙 明日 兩個切換鈕，點一下即可切換查看。
  2. 畫面依早班（08:00~20:00）、晚班（20:00~08:00）分區，各哨點的姓名／進場時間一目瞭然。
  3. 右上角 ⟳ 可手動重新整理。
🕒 每天 08:00 系統會自動把「明日哨表」內容轉為「今日哨表」；若當天哨表還沒排定，會顯示「尚未更新」提示，不會誤看到舊資料。
🚚 物流車輛統計
核心工具
  1. 於「登記」頁選擇車輛分類：1.9噸／3.5噸／8噸以上。
  2. 用 － / ＋ 輸入幾輛，登記時間自動採「送出當下」。
  3. 有常用組合時，直接點下方快捷登記按鈕一鍵送出，不用重選分類與數量。
  4. 「今日累計」小卡即時顯示當天三分類各自的總數。
  5. 切到「查紀錄」頁可選日期查當天明細，或「查看整月」看每日 × 分類統計。
「設定」頁（管理員限定）可維護快捷登記組合，全員登記頁會同步看到最新快捷按鈕。
☁️ 資料上傳工具　·　🅿️ 停車場車位　·　🚗 過夜車輛登記
核心 / 門禁
  • 資料上傳：依畫面選擇檔案（如班表 Excel）上傳。
  • 停車場車位：輸入數據計算可用車位。
  • 過夜車輛登記：登記夜間停放車輛車牌與資訊。

5工號狀態與返回主選單

  • 各工具會自動帶入你的工號，操作都會記錄是誰做的。
  • 工具內按 「返回主選單」 會回到首頁，不需要重新登入（會保留登入狀態）。
  • 要換人或結束，按首頁的「登出帳號」。

6常見問題 FAQ

看不到某個工具該工具未開放給你的職務，屬正常。需要請洽主管。
送出後說失敗多為網路不穩，請確認訊號後重試；仍失敗回報主管。
照片上傳很慢照片較大需時間，請耐心等「處理中」跑完，勿重複按。
每次都要重新登入登入時勾「記住我」即可自動登入。
手機號碼開頭 0 不見系統已修正，緊急聯絡清單會正確顯示開頭 0。
